glosslint ships two presets, `tech` and `inclusive`. They share no keys, so extending both has no collisions.

## Tech preset

`glosslint/presets/tech` has 477 product and technology names (`GitHub`, `iOS`, `Wi-Fi`, `Apple Pay`), generated by [`scripts/tech.ts`](https://github.com/onmax/glosslint/blob/main/scripts/tech.ts) from [case-police](https://github.com/antfu/case-police) 2.2.1 (MIT License, see [`NOTICE`](https://github.com/onmax/glosslint/blob/main/NOTICE)).

Every entry is `exact` with `skip: ["lower", "upper"]`, so `github` and `GITHUB` pass while `Github` is reported. Seven joined spellings sit in `allow` alongside their spaced terms so both forms pass: `AntDesign`, `AntDesignVue`, `CompositionAPI`, `GraphRAG`, `NaiveUI`, `TailwindCSS`, and `WindiCSS`. See [Coming from case-police](/guide/case-police).

## Inclusive preset

`glosslint/presets/inclusive` has 37 inclusive wording terms (`allowlist` for `"whitelist"`, `staffed` for `"manned"`, `placeholder` for `"dummy data"`) with descriptions, avoid reasons, and `Good`/`Bad` examples.

Words with a plain technical sense only appear inside specific phrases such as `"master server"`, `"master node"`, `"master database"`, `"master process"`, and `"dummy data"`.

## Extending presets

In [`.agents/glossary.md`](/guide/glossary):

```md [.agents/glossary.md]
# Glossary

Extends: tech, inclusive
```

In [`defineCorpus`](/guide/corpus):

```ts [glosslint.config.ts]
import { defineCorpus, fromGlossary } from "glosslint";
import inclusive from "glosslint/presets/inclusive";
import tech from "glosslint/presets/tech";

export default defineCorpus({
  extends: [tech, inclusive, fromGlossary()],
});
```

## Replacing a preset term

Define a term with the same key to replace a preset entry whole (fields do not merge). Adding `## GitHub` drops `tech`'s `skip: ["lower", "upper"]`, so `github` and `GITHUB` are checked too:

```md [.agents/glossary.md]
# Glossary

Extends: tech

## GitHub
```

See [Merge order](/guide/corpus#merge-order) for how keys, `allow`, and `casing` merge.

## Switching a preset term off

Add its spellings to `Allow:` (or `allow`). For multi-word tech terms, allow both the spaced and joined forms, because spaces in `Allow:` match separators rather than joined words:

```md [.agents/glossary.md]
# Glossary

Extends: tech, inclusive
Allow: Apple Pay, ApplePay, whitelist
```
